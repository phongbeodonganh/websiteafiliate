The color-format constraint closes the last CONCERNS #1–#11 vector this phase maps (stored admin colors reach every visitor's DOM via the root layout).

Output: `gemini_api_key` schema field + masked/accepting settings API, secret-free `src/lib/gemini.ts` + AI route, three new D-08 gates in the plan-02 regression file, and hex color-format validation on the admin color injection points (SEC-03).
</objective>
