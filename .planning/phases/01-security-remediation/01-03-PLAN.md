<objective>
Restrict affiliate `base_url` (and `product_url` on create) to http(s) schemes at the CMS API write boundary — 400 on violation, DB unchanged — so a `javascript:`/`data:` URL can never reach the 302 redirect or the Jina scrape target (AFF-01; CONCERNS #9 / SEC-07).

Purpose: The affiliate link store is the source of every outbound redirect; scheme validation at storage time makes every downstream consumer (302 redirect, sub_id append, scraping) structurally safe.

Output: `isHttpUrl` helper in src/lib/seo.ts, validation wired into POST + PUT, integration test matrix.
</objective>
