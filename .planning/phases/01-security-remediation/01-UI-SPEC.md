# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope note:** Phase 1 is a security-remediation phase. Its **only** user-facing UI surface is the rebuilt blacklist warning page at `/blocked` (CONTEXT.md D-09/D-10/D-11). Everything else in the phase (seed deletion, canonical JWT swap, rate limiting, ReDoS fixes, CI gates, `scripts/reset-admin.ts`) is backend/CI/ops work with **no UI contract**. This spec binds only `/blocked`; do not invent new UI for other phase work.

## Interaction & Security Contract

Binding behavior for the executor (from D-09/D-10/D-11 + RESEARCH.md `/blocked` flow):

1. **Pure RSC.** `src/app/blocked/page.tsx` is an async server component with `export const dynamic = 'force-dynamic'`. Zero `'use client'`, zero `useEffect`, zero client fetches on the page.
2. **Next.js 16 contract:** `await searchParams` (Promise); use `redirect()` from `next/navigation` inside the page (not `NextResponse`).
3. **Ref resolution:** validate `ref` as a 24-hex ObjectId (`mongoose.isValidObjectId`) → invalid/missing → `redirect('/')` before any DB call. Valid ref → `ClickLogModel.findById(ref)` → `AffiliateLinkModel.findById(log.affiliate_link_id)` → blocked check. Log not found, link not found, or link **not** currently blacklisted → `redirect('/')` (race-tolerant, preserves D-11 behavior).
4. **Fail-closed on DB error:** if the DB connection/lookup throws *after* a valid ref is accepted, render the generic fail-closed copy (see Copywriting: error state) — never a raw Next.js error screen, never a bounce to the offer.
5. **XSS-safety (the point of this page):** every blacklist-supplied string renders as a **React text child**. `dangerouslySetInnerHTML` is banned on this page; no raw HTML interpolation anywhere. No `sanitize-html` needed — text children are structurally safe (RESEARCH.md "Don't Hand-Roll").
6. **No third-party origins:** no `cdn.tailwindcss.com` Play CDN, no external scripts, no images from new hosts (status mark is inline SVG; `img-src` untouched). No `proxy.ts` changes — the existing matcher already covers `/blocked` with CSP (Pitfall 7).
7. **No new dependencies, no new client JS.** Styling via Tailwind 4 build pipeline + the existing globals.css token set.
8. **Accessibility:** `<main>` wraps content; H1 is the labelled heading (`aria-labelledby`); status mark is `aria-hidden="true"`; `:focus-visible` ring in accent red (`outline: 3px solid #B91C1C; outline-offset: 3px`, matching `result.module.css`); hover-lift disabled under `prefers-reduced-motion` (inherited convention).
9. **States not rendered by the page:** the 429 rate-limit response and over-cap click/redirect dedupe are API responses with no UI in this phase — out of contract.

## UI Considerations

Applicable state considerations resolved: 6 covered, 2 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | `/blocked?ref` param | ✅ covered | Missing/invalid `ref` (non-24-hex) redirects to `/` before any render — no empty state exists (D-10: no attacker-controlled text in URLs) |
| loading | `/blocked` page | ✅ covered | Not applicable — pure server-rendered RSC, no client fetch or in-flight UI; the 302 lands on a fully rendered page |
| error | DB resolution on `/blocked` | ✅ covered | DB failure renders the documented fail-closed generic copy (Copywriting: "Body — DB-failure fail-closed"), never a crash screen or bounce to the offer |
| populated | blocked link with full data | ✅ covered | Eyebrow + H1 + description with `{projectName}` + receipt (Project / Block reason / Blocked countries) + primary CTA, per contract |
| partial | reason / blocked_countries fields | ✅ covered | Empty reason → default block-reason copy; empty country list → row omitted entirely (no empty "Blocked countries: —" row) |
| overflow | receipt values / country list | 🧪 backstop | Long receipt values and multi-country lists wrap (`overflow-wrap: anywhere`), never truncate or scroll — held-out/visual backstop test |
| zero-one-many | blocked countries list | ✅ covered | 0 countries → row omitted; 1..n → values joined `", "` under the fixed `Blocked countries` label (no singular/plural copy switch needed) |
| long-text | `project_name` / `reason` from imported sheets | 🧪 backstop | Imported sheet strings render full-width with wrap, no ellipsis, no max-length clamp on security data — H1 is fixed copy so no long-title risk — backstop |
