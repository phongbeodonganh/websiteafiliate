<objective>
Make the blacklist bulk import responsive for large sheets and make the retroactive sweeper batched, boundary-safe, and reversible: the import persists rows and returns immediately while the sweep runs post-response via `after()`; a new admin re-sweep action runs the sweep plus a restore that only ever touches swept (`blacklisted`) campaigns.

Purpose: A 300-row paste currently serializes 300+ `save()` calls inside one HTTP response (CONCERNS perf; RESEARCH D-05/D-06), and a swept campaign has no path back to active (D-07/D-08). This plan delivers the V5.2 §1.9 import contract with correct, reversible sweep semantics.

Output: batched + restoring sweep functions in `src/lib/blacklist.ts`, a `scheduleAfterResponse` helper, a reworked import route, a new re-sweep route, and two new test files.
</objective>
