<objective>
Fix crawl hygiene and list API performance: make the legacy redirect permanent (308), add noindex metadata for search URLs, switch sitemap/robots to ISR, and strip full HTML content from list API responses.

Purpose: SEO rankings depend on clean crawl signals (permanent redirects transfer equity, noindex prevents search-result-page spam in Google's index), and list APIs sending full article HTML wastes bandwidth since the UI only uses excerpts.

Output: 7 modified source files, 4 new test files.
</objective>

| T-03-05 | Information Disclosure | List API Cache-Control leaking draft content | low | mitigate | select(-content) strips HTML; status filter {status: 'published'} is already in place; Cache-Control only applies to the already-filtered published articles |
| T-03-06 | Tampering | 308 permanent redirect to wrong target | high | mitigate | Slug mapping is 1:1 by construction; non-existent slugs pass through to the /article/ page which handles the 404 via notFound(); checkpoint confirms intent |
